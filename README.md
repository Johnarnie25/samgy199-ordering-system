# Samgy199 Ordering System

## Overview

A full-stack restaurant ordering system developed as part of a capstone project, designed to streamline customer ordering and improve operational efficiency for Samgy199. The system centralizes order management and enhances service speed.

## Features

* Digital menu display and ordering system
* Order processing and transaction tracking
* Centralized system for managing customer orders
* Structured workflow to ensure accurate order handling
* Improved coordination between ordering and service operations

## Tech Stack

* PHP
* JavaScript
* MySQL
* HTML / Bootstrap
